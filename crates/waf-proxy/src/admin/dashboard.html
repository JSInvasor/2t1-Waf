Sample window 5s · escalates when blocks/sec exceed the threshold, de-escalates at ¼ of it. 30s cool-down between level changes.

Challenge mode

How freshly-arriving visitors are vetted when UAM is engaged or the score crosses the challenge threshold.

PoW = browser solves a SHA-256 proof. Interactive = checkbox + behavioural signal. Combined = both.

Heuristic defenses

9 layers · all hot-toggleable

Bot score — header completeness, UA / sec-ch-ua consistency, modern browser fingerprints.
Behavior — per-IP URL diversity, inter-arrival regularity, method bias, UA churn.
DDoS patterns — GET-with-body, empty Connection, CORS-less OPTIONS, cache-buster spam, NUL bytes, query bloat.
Honeypots — instant ban on requests to /.env, /wp-config.php, scanner trap paths.
Subnet — /24 (IPv4) and /64 (IPv6) rate & in-flight ceiling, catches botnets sharing a subnet.
Replay — same (method+path+UA) hash hammered 25× from one IP in 30s.
Distributed UA — single User-Agent observed from 8+ distinct IPs in 60s (botnet signature).
Good-bot whitelist — Googlebot / Bingbot / Yandex / Baidu / Apple / Meta / LinkedIn / Twitter / Discord / DuckDuckGo with reverse-DNS verification. Spoofers add +60 score; first-hit pending bots get a lenient pass.
Silent BIC — invisible browser integrity check served before the heavyweight PoW. Real browsers complete a tiny SHA-256 probe in <100 ms and get a HMAC-signed cookie tied to their /24; bots that don't run JS never receive it.
